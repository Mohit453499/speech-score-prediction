# Speech Score Prediction

## Project Overview
This project focuses on predicting scores from speech recordings using audio processing, speech transcription, linguistic feature extraction, and machine learning techniques.

## Objectives
- Process and analyze audio recordings.
- Convert speech into text using Whisper.
- Extract grammar and fluency-related features.
- Explore transformer-based models such as DeBERTa and machine learning models.
- Evaluate model performance and generate predictions.

## Technologies Used
- Python
- Jupyter Notebook
- Whisper
- DeBERTa
- Audio Processing
- Machine Learning
- Natural Language Processing (NLP)
- Pandas and NumPy

## Project Workflow
1. Load and preprocess audio data.
2. Apply noise reduction where required.
3. Transcribe speech into text.
4. Extract linguistic features.
5. Train and evaluate prediction models.
6. Generate predictions and export results to CSV.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Obtain the required dataset and configure the file paths.
4. Open the notebook in Jupyter Notebook or Google Colab.
5. Run the notebook cells in order.

## Note
Model performance depends on the dataset, preprocessing, and training configuration. Refer to the notebook for the implemented experiments and evaluation results.
